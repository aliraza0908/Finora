How Finora is built

Finora is a full-stack web application. Each layer has one job, and the layers talk to each other in one direction: browser, then server, then database.

Frontend

  • 9 pages in HTML5, CSS3 and plain JavaScript
  • Lives in /public
  • Calls the backend with fetch()
  • Validates forms before sending

Backend

  • Node.js with Express, in /server
  • REST API under /api
  • Checks login, validates input again, runs SQL
  • Passwords hashed with bcrypt, sessions in httpOnly cookies

Database

  • SQLite file: server/data/finora.db
  • Tables: users, transactions, contacts
  • Every query is parameterised
  • Deleting a user removes their transactions

Follow one request through the system

  1. You save an expense.
    The form on the Add transaction page checks the fields, then sends POST /api/transactions.
  2. The server verifies you.
    Express reads your login cookie, confirms who you are and validates the amount, date and category again.
  3. The database stores it.
    A prepared INSERT writes the row against your user id, so only you can ever read it back.
  4. The dashboard updates.
    GET /api/summary adds up your rows and the page redraws your balance.

Tip: press the Under the hood button at the bottom right of any page to watch these API calls happen live.
